# 💻 Portfólio Profissional

Um portfólio front-end moderno, elegante e de alta performance, desenvolvido com foco total em tecnologias nativas da web.

---

## 🇧🇷 Português

### 🚀 Sobre o Projeto

Este projeto foi construído do zero utilizando apenas **HTML5, CSS3 e JavaScript (Vanilla)**, garantindo uma navegação extremamente rápida, leve e compatível com qualquer dispositivo ou navegador moderno, sem dependências de back-end ou frameworks pesados.

### ✨ Funcionalidades

- 🎨 **Design Autêntico:** Estrutura visual limpa e focada em identidade moderna.
- ⚡ **Performance Nativa:** Zero peso de _builds_ complexos, carregando instantaneamente.
- 📱 **Responsividade Total:** Adaptado perfeitamente para desktops, tablets e smartphones.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica e estruturação limpa.
- **CSS3:** Estilização avançada com variáveis globais e animações fluidas.
- **JavaScript (Vanilla):** Lógica nativa modularizada para interatividade e dinamismo.

## 🇬🇧 English

### 🚀 About the Project

This project was built from scratch using only **HTML5, CSS3, and Vanilla JavaScript**, ensuring extremely fast, lightweight navigation compatible with any modern device or browser, without heavy back-end dependencies or frameworks.

### ✨ Features

- 🎨 **Authentic Design:** Clean visual structure focused on modern identity.
- ⚡ **Native Performance:** Zero heavy complex builds, loading instantly.
- 📱 **Full Responsiveness:** Perfectly adapted for desktops, tablets, and smartphones.

### 🛠️ Technologies Used

- **HTML5:** Semantic markup and clean structure.
- **CSS3:** Advanced styling with global variables and smooth animations.
- **Vanilla JavaScript:** Modular native logic for interactivity and dynamism.
